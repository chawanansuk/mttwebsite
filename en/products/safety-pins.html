FAQ

Which size is smallest / largest?
000 is the smallest (~1.9 cm) and 7 the largest (~8.5 cm).
Which size for race bibs?
Size 2 (38 mm) is the usual choice, and some organizers pick the smaller size 0 (28 mm). Four pins per runner; order by the box for events.
Which size for diapers?
Size 4 (56 mm), a.k.a. blanket/diaper pins — or plastic-head locking pins for extra safety.
Which size for price tags?
000 or 00 — small enough for hang tags; the garment-trade standard.
How many in a gross? What is 2/0?
A gross is 144 pins (12 dozen). 2/0 = size 00 and 3/0 = size 000 — same sizes, different notation.
Do silver pins rust? Are they stainless?
Nickel-plated spring steel (not true stainless) — rust-resistant when kept dry; avoid prolonged moisture.
How is pin length measured?
Cap-to-coil overall length — approximate; makers vary by ±2–3 mm.
Minimum order?
From a dozen bunch to full boxes — bigger orders get better rates. LINE us the size and quantity.

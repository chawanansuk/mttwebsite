# ความเร็วเว็บบนมือถือ: ตัวเลขตั้งต้น

วัดเมื่อ 21 พ.ย. 2569 ด้วย Lighthouse 12 โหมดมือถือ (จำลองมือถือระดับกลางบนเน็ต 4G ช้า)
แต่ละหน้าวัด 3 รอบ ใช้ค่ากลาง

**ข้อจำกัด:** วัดจากไฟล์ในเครื่องผ่านเซิร์ฟเวอร์จำลองที่บีบอัดไฟล์และตั้ง cache แบบเดียวกับ Vercel
ไม่ได้วัดจากเว็บจริง (เครื่องที่ใช้วัดเข้า mtthardware.com ตรง ๆ ไม่ได้) และเป็นค่าจากห้องแล็บ ไม่ใช่ค่าจากผู้ใช้จริง
ค่าจากผู้ใช้จริงดูได้ใน Search Console เมนู "Core Web Vitals" เมื่อมีคนเข้าเว็บมากพอ

\* รวมคลิป 0.7 MB ที่เริ่มโหลดหลังหน้าโหลดเสร็จแล้ว ไม่กระทบความเร็วที่เห็นตอนเปิดหน้า

เกณฑ์ "ดี" ของ Google: LCP ไม่เกิน 2.5 วิ, CLS ไม่เกิน 0.1, INP ไม่เกิน 200 ms
(Lighthouse วัด INP ไม่ได้ ใช้ TBT แทน ยิ่งต่ำยิ่งดี) ทุกหน้าผ่านเกณฑ์
หน้าเข็มกลัดชิดเส้นที่สุด (LCP 2.5 วิ) ถ้าจะปรับ เริ่มที่รูปตารางขนาดด้านบนของหน้านี้

## คะแนนด้านอื่น

- SEO 100 ทุกหน้า ยกเว้นหน้ารวมเครื่องมือและหน้าประแจได้ 92 เพราะปุ่ม "ส่งขอราคาทาง LINE" ในแถบรายการขอราคาไม่มี `href` จนกว่าจะเลือกสินค้า แก้แล้ว
- การเข้าถึง 100 ยกเว้นหน้าประแจ 96 เพราะปุ่ม + ข้างรหัสสินค้าชิดลิงก์รหัสจนพื้นที่กดทับกัน แก้แล้ว (เว้นระยะเพิ่ม)
- แนวปฏิบัติที่ดี 96 ทุกหน้า มาจากสคริปต์ Vercel Analytics ที่ไม่มีในเครื่องที่ใช้วัด (404) บนเว็บจริงไม่เป็น

## วัดซ้ำเมื่อไหร่

- หลังเพิ่มรูป วิดีโอ หรือสคริปต์ใหม่ในหน้าหลัก
- ทุก 3 เดือน เทียบกับตารางนี้
- ถ้า Search Console เตือนเรื่อง Core Web Vitals ให้ดูหน้าที่ถูกเตือนก่อน

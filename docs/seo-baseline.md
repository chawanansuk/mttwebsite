# วัดผล SEO ของ mtthardware.com

เอกสารนี้สำหรับเจ้าของร้าน บอกวิธีเปิดเครื่องมือวัดผล 2 ตัว และตัวเลขที่ต้องดูทุกสัปดาห์
เป้าหมายคือรู้ว่าเว็บเราอยู่เหนือร้านที่ขายเข็มกลัดตราสิงโตต่อหรือยัง โดยใช้ตัวเลขจริง ไม่ใช่ความรู้สึก

**ข้อจำกัดที่ต้องรู้:** เราดูยอดคนเข้าเว็บของร้านอื่นไม่ได้ ใครบอกว่าดูได้คือเดา
สิ่งที่วัดได้คือ ตำแหน่งของเราบน Google จำนวนคลิกเข้าเว็บเรา และจำนวนคนที่กดทัก LINE จากเว็บ

## 1. เปิด Google Search Console (ทำครั้งเดียว ใช้เวลาราว 10 นาที)

1. เข้า https://search.google.com/search-console ด้วยบัญชี Google ของร้าน
2. กด "เพิ่มพร็อพเพอร์ตี้" เลือกแบบ **คำนำหน้า URL** แล้วพิมพ์ `https://mtthardware.com/`
3. เลือกวิธียืนยัน **แท็ก HTML** จะได้บรรทัดหน้าตาแบบนี้
   `<meta name="google-site-verification" content="ABC123...">`
4. คัดลอกเฉพาะค่าใน `content` (ตัวอย่าง `ABC123...`) ส่งให้ผู้ดูแลเว็บ
   ผู้ดูแลจะใส่ใน `assets/js/shop-config.js` ช่อง `SEARCH_CONSOLE_VERIFY` แล้วรัน `npm run gen`
   ระบบจะใส่แท็กลงหน้าแรกให้เอง
5. รอเว็บอัปเดตราว 2 นาที แล้วกลับไปกด "ยืนยัน" ใน Search Console
6. เมนู "แผนผังเว็บไซต์" ส่ง `https://mtthardware.com/sitemap.xml`
7. ตัวเลขชุดแรกจะเริ่มขึ้นหลังยืนยันราว 2–3 วัน ย้อนหลังได้ไม่เกินวันที่ยืนยัน
   ยิ่งเปิดเร็ว ยิ่งได้เส้นฐานเร็ว

## 2. เปิด Vercel Web Analytics (ทำครั้งเดียว)

1. เข้า https://vercel.com เลือกโปรเจกต์ `mttwebsite`
2. แท็บ **Analytics** กด **Enable**
3. เว็บมีสคริปต์ `/_vercel/insights/script.js` อยู่ทุกหน้าแล้ว ไม่ต้องแก้โค้ด
4. หลังเปิดจะเห็นยอดเข้าชมแต่ละหน้า และแหล่งที่มา (Google, LINE, Facebook, พิมพ์ตรง)

**เรื่อง event:** เว็บส่ง event เหล่านี้ไว้แล้ว ถ้าแผน Vercel รองรับ custom events จะเห็นในหน้า Analytics

| event | เกิดเมื่อ |
|---|---|
| `line_click` | กดปุ่มหรือลิงก์ LINE จุดไหนก็ได้ในเว็บ (มีช่อง where บอกว่ากดจากตรงไหน) |
| `phone_click` | กดเบอร์โทร |
| `race_quote` | กดขอราคาจากเครื่องคำนวณหน้าเข็มกลัดงานวิ่ง |
| `add_to_cart` | ใส่ไฟฟู่ลงตะกร้า |
| `order_copy` / `order_sent` | คัดลอกรายการสั่งซื้อ / ส่งรายการทาง LINE |

ถ้าแผนที่ใช้อยู่ไม่รองรับ custom events จะเห็นแค่ยอดเข้าชมหน้า ซึ่งยังพอใช้วัดผลได้
ให้ดูยอดเข้าชมหน้าสินค้าแทน และนับจำนวนแชท LINE ที่ลูกค้าบอกว่าเจอจากเว็บ

## 3. คำค้นเป้าหมาย 34 คำ

รายการเต็มอยู่ใน `data/seo-targets.json` แบ่ง 4 กลุ่ม คือแบรนด์และชื่อร้าน เข็มกลัด ไฟฟู่ และเครื่องมือช่าง
ทุกคำผูกกับหน้าของเราที่ควรขึ้น ผู้ดูแลเว็บรัน `npm run seo` เพื่อตรวจว่าหน้านั้นพร้อมหรือยัง
(มีคำค้นในหัวข้อและย่อหน้าแรก title ไม่ยาวเกิน มี schema ครบ)
`npm run seo` ไม่ได้วัดอันดับ Google มันตรวจแค่ว่าหน้าเราพร้อมแข่ง

## 4. ทุกวันจันทร์ ใช้เวลาราว 20 นาที

เปิดไฟล์ `docs/seo-tracking.csv` ใน Excel หรือ Google Sheets ทำสำเนาแถวทั้ง 34 แถว ใส่วันที่ของสัปดาห์นั้น แล้วกรอก

**จาก Search Console** เมนู "ผลการค้นหา" ตั้งช่วงเวลา 7 วันล่าสุด
1. กด "+ ตัวกรอง" เลือก "คำค้นหา" แล้วพิมพ์คำค้นจากตาราง
2. จดตัวเลข 4 ตัว คือ คลิก การแสดงผล CTR และตำแหน่งเฉลี่ย
3. ถ้าคำนั้นยังไม่มีข้อมูล ให้เว้นว่าง อย่ากรอกเลขเอง

**ตรวจมือว่าอยู่เหนือร้านขายต่อไหม**
1. เปิดหน้าต่างไม่ระบุตัวตน (Incognito) ในมือถือ ค้นคำนั้นใน Google
2. ดูหน้าแรก ถ้าเว็บเราอยู่สูงกว่าร้านที่ขายเข็มกลัดตราสิงโตต่อ จด "เหนือ" ถ้าต่ำกว่าจด "ใต้"
   ถ้าเว็บเราไม่อยู่หน้าแรกจด "ไม่ติดหน้าแรก"
3. ผลค้นหาแต่ละเครื่องต่างกันเล็กน้อย ให้ใช้มือถือเครื่องเดิมทุกสัปดาห์

**จาก Vercel Analytics** ช่วงเวลา 7 วันล่าสุด
- ยอดเข้าชมหน้าแรก หน้ารวมเข็มกลัด หน้าไฟฟู่ และหน้าเข็มกลัดงานวิ่ง
- สัดส่วนคนที่มาจาก Google
- จำนวน `line_click` และ `race_quote` ถ้าเห็น

## 5. อ่านตัวเลขยังไง

- **การแสดงผลขึ้นแต่คลิกไม่ขึ้น** แปลว่า Google เริ่มแสดงเว็บเราแล้ว แต่หัวข้อหรือคำอธิบายยังไม่ดึงให้กด
  แจ้งผู้ดูแลให้ปรับ title และ description ของหน้านั้น
- **ตำแหน่งเฉลี่ยดีขึ้นต่อเนื่อง 3 สัปดาห์** แปลว่ามาถูกทาง อย่าเปลี่ยนหน้านั้นบ่อย
- **คลิกขึ้นแต่ line_click ไม่ขึ้น** แปลว่าคนเข้ามาแต่ไม่ทัก ให้ดูว่าหน้านั้นมีราคาหรือยัง
  การไม่มีราคาเป็นเหตุผลอันดับต้น ๆ ที่คนกดออก
- **อย่าสรุปว่าแซงแล้ว** จนกว่าจะเห็นคำว่า "เหนือ" ในคำค้นกลุ่มเข็มกลัดเกินครึ่ง ติดต่อกัน 4 สัปดาห์

## 6. สิ่งที่ช่วยให้ตัวเลขขึ้นเร็วที่สุด (ร้านต้องทำ)

1. ส่งราคาเข็มกลัดทุกเบอร์ให้ผู้ดูแลเว็บ (ใส่ใน `data/pins.json`)
2. เปิด Search Console ตามข้อ 1 ให้เร็วที่สุด เพราะข้อมูลย้อนหลังได้ไม่เกินวันที่ยืนยัน
3. เปิด Google Business Profile ตาม `docs/google-business.md`
4. ส่งรูปจริงของร้านและสินค้า
